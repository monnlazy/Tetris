# Tetris Classic Remastered

Proyek game Tetris modern berbasis web dengan teknologi Pure HTML5, CSS3, dan Plain JavaScript (ES6+).

## 🚀 Fitur Utama
- **Aturan Tetris Modern Engine**: Menggunakan sistem *7-Bag Randomizer*, *Ghost Piece*, *Hold Piece*, serta *Next Queue (5 Balok)*.
- **Sistem Scoring Modern**: Kalkulasi Single, Double, Triple, Tetris, Back-to-Back, dan Combo.
- **Responsif & Cross-Platform**: Dukungan penuh untuk Desktop (Keyboard) dan Mobile HP/Tablet (Touch Screen Virtual Controls).
- **Audio Synthesizer Engine**: Web Audio API terintegrasi langsung untuk memutar SFX tanpa lag eksternal.
- **Save System LocalStorage**: Menyimpan statistik permainan secara permanen di browser.
